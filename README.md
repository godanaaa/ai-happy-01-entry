Make the AI judge happy: your program writes one image, an AI judge compares the images two at a time and picks the one that makes it happier, and the 100 best win rates share $250.

This entry is a warm sunrise scene: a small friendly robot and a smiling developer sharing a steaming mug of coffee, with butterflies and birds rising above them. The program copies the original image to `/output/entry.png`, byte for byte, deterministically.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
